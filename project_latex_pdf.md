# Project: Markdown → LaTeX → PDF

## Goal

Demonstrate a full document-authoring loop inside a remote Claude Code cloud session:
choose a topic, write a structured markdown document, convert it to LaTeX, and compile
it to a clean PDF — retrying compilation automatically until there are no errors.

## Task prompt (send this to `claude --remote`)

```
Choose a self-contained mathematical or scientific topic suitable for a 2–4 page
technical document (e.g. the Golden Ratio, Euler's identity, or Bayes' theorem).

Then carry out the following steps in order:

1. Write `doc.md` — a well-structured markdown document covering the topic.
   Include: a title, abstract, several sections, at least one equation block,
   and a short conclusion.

2. Convert `doc.md` to `doc.tex` using pandoc:
       pandoc doc.md -o doc.tex --standalone

3. Compile `doc.tex` to PDF with pdflatex:
       pdflatex -interaction=nonstopmode doc.tex

4. Inspect the log for errors. If errors exist, fix `doc.tex` and repeat step 3.
   Keep iterating until pdflatex exits with code 0 and the log contains no errors.
   Run pdflatex twice on the final clean pass so cross-references resolve.

5. Confirm that `doc.pdf` exists and report the final topic and section titles.
```

## Custom environment requirements

A setup script must install a TeX distribution and pandoc before the session starts.
See `remote_teleport_guide.md` for where to paste this script.

```bash
#!/usr/bin/env bash
set -euo pipefail
apt-get update -y
apt-get install -y --no-install-recommends \
    texlive-latex-base \
    texlive-latex-recommended \
    texlive-latex-extra \
    texlive-fonts-recommended \
    pandoc
```

## Expected outputs

| File | Description |
|------|-------------|
| `doc.md` | Source markdown document |
| `doc.tex` | LaTeX file generated by pandoc |
| `doc.pdf` | Final compiled PDF |
| `doc.log` | pdflatex log (useful for debugging) |

## What makes this a good remote-teleport test

- The compilation loop requires real shell execution — it cannot be faked by file
  editing alone.
- The setup script tests environment customization and caching.
- The final `doc.pdf` is a concrete binary artifact to inspect after teleporting back.
- Iterative error-fixing exercises Claude's ability to read compiler output and
  correct LaTeX source autonomously.
